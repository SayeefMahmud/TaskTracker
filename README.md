# DoTo — Task Tracker

Spatial Glass Task Tracker built with Flutter.

## Features
- **Spatial Glass Design**: Light and dark mode support with blur gradients, micro-interactions, and custom frosted glass surfaces.
- **Priority & Categorization**: Work, Personal, Health, Home with high/medium/low priority filtering.
- **Persistent High-Priority Notifications**: Sticky notification shade alerts for high-priority tasks until marked completed.
- **Recurrence & Subtasks**: Daily, weekly, monthly repeating tasks and multi-step checklists.
- **Analytics & Heatmaps**: Habit tracking streaks, daily completion statistics, and category duration breakdowns.
- **Home Screen Widgets**: Android & iOS widgets via `home_widget`.
